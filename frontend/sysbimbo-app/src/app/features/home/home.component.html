CRUD maestro sobre SQL Server

Administra tiendas, SKUs, campanias, cuotas y programaciones desde una sola interfaz.

Esta version inicial conecta Angular con un backend .NET 8 y expone operaciones CRUD, filtros y paginacion para las tablas maestras del proyecto.

Ir a Tiendas Ir a SKUs Ir a Campanias Ir a Cuotas Ir a Programaciones

Incluye

  • Filtros por criterios de negocio
  • Creacion y edicion con formularios reactivos
  • Mensajes de exito y error
  • Paginacion basica para tablas grandes
  • Endpoint de salud para validar SQL Server
  • Modulo adicional para la tabla Campania
  • Modulo adicional para la tabla FactCampaniaCuota
  • Modulo adicional para la tabla Programacion
